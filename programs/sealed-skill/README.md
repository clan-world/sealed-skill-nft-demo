# Sealed Skill Solana Program Scaffold

This Anchor program is the future on-chain verification path.

The MVP UI does not require it to run. The UI uses Solana devnet token mint/transfer plus the API coordinator.

What this program is meant to become:

- On-chain TEE registry.
- On-chain artifact registry.
- Transfer capsule verification.
- Transfer approval consumption.
- Future Token-2022 Transfer Hook or Metaplex Core integration.

Before production, add:

- Real TEE signature verification path.
- Full transfer hook integration.
- Admin governance.
- Real attestation registry integration.
